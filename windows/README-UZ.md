# BIMO AI + LocalAI Studio — Windows 0.7.1

BIMO AI bir installerda liquid Moshi paneli, LocalAI Studio, Telegram, CMD/PowerShell, GitHub, tanlangan oyna vositalari va mahalliy o‘zbekcha ovozni o‘rnatadi.

1. [GitHub Release](https://github.com/Ahmadjon0worker/BIMO-AI/releases/tag/v0.7.1) ichidagi `BIMOAI-Windows-0.7.1-setup.exe` faylini ishga tushiring.
2. Start menyusidan **BIMO AI LocalAI Studio**ni oching; tray menyusi ham mavjud.
3. **Tizim holati** orqali xizmatni tekshiring, keyin Ollama, Gemini yoki Groq sozlang. Oddiy Telegram va Windows vositalari AI modelsiz ham ishlaydi.
4. **Telegram va Windows vositalari** orqali shaxsiy Telegram, terminal, GitHub, Desktop, Ovoz va **Moshi AI va xotira**ni oching.
5. **Ctrl+Shift+Space**ni ushlab gapiring, qo‘yib yuboring. «OK Bimo», «OK Moshi» va eski wake iboralari ixtiyoriy davomli tinglashda ishlaydi.

Panelni **⠿** tutqichidan sudrang: tepa/pastda gorizontal, yonda vertikal, burchakda kvadrat. Kengaygan panelni **−** bilan yig‘ing. Liquid Moshi o‘sha besh burchakli animatsion hamroh bo‘lib qoladi.

Eski Qanot AI/Coucou per-user EXE o‘rnatmasi tekshirilgan avvalgi papkada yangilanadi. Sozlamalar `%APPDATA%\Coucou`, Telegram sessiyasi `%LOCALAPPDATA%\Coucou\LocalAI` ichida; ichki `coucou.exe`, hook va CLI nomlari moslik uchun saqlanadi.
